AI Skills

Reusable instructions that teach an AI assistant to handle one kind of task the same way every time. Each skill is a folder with a SKILL.md: a name, a one-line description of when to use it, and the steps to follow.

Use a skill

3 steps

  1. Copy the folder

    Into ~/.claude/skills/ for every project, or a project's .claude/skills/ for one.

  2. Start a new session

    Claude Code reads skills when a session starts.

  3. Invoke it

    Type /skill-name, or let the assistant pick it from its description.

git clone https://github.com/vash-fiery/AI-Skills

Add a skill

CONTRIBUTING

  1. Create a folder under skills/

    Lowercase and hyphenated, for example code-review.

  2. Write the SKILL.md

    The name in its frontmatter must match the folder name, and it needs a description.

  3. Run the check

    python scripts/validate_skills.py confirms every skill is well-formed. CI runs the same check on each pull request.

  4. Open a pull request

    Add the skill to the README table. The PR template has a short checklist.
